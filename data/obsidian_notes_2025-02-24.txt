with the goal of establishing which model is best\n- This is a very large search space given $p \\choose k$ and $2^p$ possibilities\n![[Pasted image 20250212140022.png]]\n- Step 2 is used to identify the best model for a given subset size, and reduces the problem from $2^p$ to $p + 1$ (null model plus number of predictors, as we are choosing from the created for loop)\n- The accuracy will monotonically increase as $p$ increases, which will overfit, therefore we must use [[Cross Validation]] to assert that test accuracy is also increasing\n\t- For k-fold CV, we will average the accuracy across folds\n- Plotting the accuracy for each model $p$ should help in seeing a cut off point\n\t- EX) from the three-variable model on, there is little improvement in accuracy, as a result of including additional predictors\n- One problem with best subset selection is **computation limitations**\n\t- computationally infeasible for values of $p$ greater than 40\n- The larger $p$ gets the higher the propensity to overfit\n\n## Stepwise Selection\n\n#### Forward Stepwise Selection\n- Forward Stepwise Selection is a computationally efficient alternative to [[#Best Subset Selection]]\n\t- This is due to it considering a much smaller subset of models\n- Starts with a null model and adds the predictor that increases the accuracy the most, until all predictors are in the model \n- This results in a search space of $1+\\frac{p(p+1)}{2}$, which is much smaller\n![[Pasted image 20250212141904.png]]\n- Step 2 gets the best model that adds one additional predictor\n- Step 3 selects the best model out of the models with different number of variables\n- Forward selection does well in practice, but is not guaranteed to find the best possible model\n- Can work in settings where the number of predictors is greater than the number of observations\n\n#### Backwards Stepwise Selection\n- Backwards Stepwise Selection is also a computationally efficient alternative to [[#Best Subset Selection]]\n- It begins with the full least squared model, and then iteratively removes the least useful predictor\n![[Pasted image 20250212142443.png]]\n- Search space is $1+\\frac{p(p+1)}{2}$\n- It is also not guaranteed to yield the best model\n- Requires having more predictors than observations\n\n#### Hybrid Approaches\n- [[#Forward Stepwise Selection]] and [[#Backwards Stepwise Selection]] give similar but not identical results\n- Hybrid models start by adding predictors to the model, but then can also take away predictors if they do not add value\n- More closely mimics [[#Best Subset Selection]], but with the computation advantages of [[#Forward Stepwise Selection]] and [[#Backwards Stepwise Selection]]\n\n#### Choosing the Optimal Model\n- Due to overfitting the training set the model containing all of the predictors will always have the smallest RSS\n- To choose a model with low test error, we can take two approaches:\n\t- **Indirectly estimate** test error by making a adjustment to the training error \n\t- **Directly estimate** test error with [[Cross Validation]]\n##### Indirect Estimate\n- The core idea is that the training error will decrease as more variables are included in the model, but the test error may not\n- Therefore we want to *adjust* the training error for the *model size* \n\n###### $C_{p}$\n$$C_{p} = \\frac{1}{n}(RSS+2d\\hat{\\sigma}^2)$$\n- **$C_{p}$** adds a penalty of $\\hat{\\sigma}^2$ to the training RSS in order to adjust for the fact that the training error tends to underestimate the test error \n- **$C_{p}$ is an unbiased estimate of test MSE\n- We would want to choose the model with the **lowest** $C_{p}$\n\n###### AIC\n$$AIC = \\frac{1}{n}(RSS+2d\\hat{\\sigma}^2)$$\n- For least squared models [[#$C_{p}$]] and AIC are proportional to each other\n- We would want to choose the model with the **lowest** AIC\n\n###### BIC\n$$BIC = \\frac{1}{n}(RSS+\\log(n) d\\hat{\\sigma}^2)$$\n- BIC is derived from a Bayesian point of view\n- BIC will tend to take on small value for a model with a low test error, and so generally we select the model that has the **lowest** BIC value\n- For models with greater than 7 observations BIC places a greater penalty than [[#$C_{p}$]] and [[#AIC]]\n\t- This can be derived from changing $2$ to $\\log{n}$ \n\n###### $Adjusted_{}R^{2}$\n$$Adjusted_{}R^{2} = 1-\\frac{\\frac{RSS}{(n-d-1)}}{\\frac{TSS}{(n-1)}}$$\n- As RSS is always decreasing as more variables are added to the model, the $R^2$ always increases as more variables are added \n- We want a **larger** $Adjusted_{}R^{2}$ \n- Once all of the correct variables have been included in the model, adding additional noise variables will lead to a small decrease in $Adjusted_{}R^{2}$\n\n##### Direct Estimate\n- We can directly estimate the test error using validation and cross validation methods\n- Direct methods have a advantage over indirect methods as they provide an actual estimate of test error, and make less assumptions about the true underlaying model\n- Can be used a wider range of model selection tasks\n- In the past CV methods were computationally expensive, and so [[#Indirect Estimate]] methods were preferred, but not CV is cheap and so is very attractive \n- **One-standard-error Rule:** First calculate the standard error estimate of the test MSE for each model size, then select the smallest model for which the estimated test error is within one standard error of the lowest point on the curve \n\t- If models are more or less equally good, we should pick the simplest model\n\n### Regularization Methods\n- Instead of [[#Subset Selection]] where we reduce the number of predictors, we can use methods that *constrain* or *regularize* the coefficient estimates\n- This shrinking of the coefficients can significantly reduce their variance \n\n#### Ridge Regression\n- Ridge Regression aims to produce coefficient estimates $\\hat{\\beta}^{R}$ that minimize $$ \\min_{\\beta} \\sum_{i=1}^{n} (y_i - \\mathbf{x}_i^T \\beta)^2 + \\lambda \\beta^{2}_{j} $$\n- We introduce $\\lambda$ which is a tuning parameter, such that $\\lambda \\ge 0$\n- The objective of ridge regression is to find coefficients that fit the data well\n- The second term ($\\lambda \\|\\beta\\|_2^2$) is referred to as a *shrinking penalty* \n\t- Small when $\\beta_{0}...\\beta_{p}$ are close to 0, and so it had the effect of shrinking the estimates of $\\beta_{j}$ to 0\n- As, $\\lambda \\rightarrow \\infty$ the impact grows\n\t- $\\lambda = 0$ is equivalent to least squares\n\t- $\\lambda = \\infty$ is equivalent to the null model\n- We will get different $\\beta$ values for every value of $\\lambda$\n- The shrinking penalty is not applied to $\\beta_{0}$\n- While estimates will tend to decrease as $\\lambda$ increases, some individual coefficients will occasionally increase\n- As $\\lambda$ increases $\\ell_{2}$ will always decrease$$\\ell_{2} = ||\\beta||_{2} = \\sqrt{\\sum^{p}_{j=1}\\beta^{2}_{j}}$$\n- Must apply ridge regression after standardizing the predictors \n- As $\\lambda$ increases, the flexibility of the ridge regression fit decreases, leading to decreased variance but increased bias\n\t- When the relationship between observations and predictors is close to linear, least squares will have low bias but high variance, this is especially true when the number of predictors is similar to the number of observations\n\t- Ridge regression works best in situations where the least squares estimates have high variance\n- Compared to [[#Subset Selection]], the computational cost is far less requiring one model fit, and is almost identical to the computational complexity of least squares\n#### Lasso Regression \n- [[#Ridge Regression]] will include all predictors within its final model, the penalty have to coefficients approach zero, but not reach zero\n\t- This will not impact accuracy, but *will hurt model interpretability* \n- Lasso regression augments ridge regression, where the lasso coefficients are $\\hat{\\beta}^{L}_{\\lambda}$ and seek to minimize $$\\min_{\\beta} \\sum_{i=1}^{n} (y_i - \\mathbf{x}_i^T \\beta)^2 + \\lambda |\\beta_{j}| $$\n- The ridge regression penalty $\\beta^{2}_{j}$ has been replaced by $|\\beta_{j}|$ in the lasso penalty\n- Lasso uses $\\ell_{1}$ penalty $$\\ell_{1} = ||\\beta||_{1} = \\sum^{p}_{j=1}\\beta_{j}$$\n- Just like [[#Best Subset Selection]] Lasso regression preforms *variable selection*\n- lasso yields a **spare model**: model that involves only a subset of the variables\n- As, $\\lambda \\rightarrow \\infty$ the impact grows\n\t- $\\lambda = 0$ is equivalent to least squares\n\t- $\\lambda = \\infty$ is equivalent to the null model\n- Depending on $\\lambda$ lasso can produce a model using any number of predictors\n\n#### Comparing Lasso and Ridge Regression\n- [[#Lasso Regression]] preforms better in settings where a relatively small number number of predictors have substantial coefficients and the remaining predictors have coefficients that are very small or that equal zero\n- [[#Ridge Regression]] preforms better when the response is a function of many predictors, all with coefficients of roughly equal size\n\n#### Selecting the Tuning Parameter\n- Using [[Cross Validation]], we can choose a grid of $\\lambda$ and compute the cross validation score for each\n\n## Dimension Reduction Methods\n- A set of methods that *transform* the predictors and then fit a least squares model using the transformed variables \n- We first **transform** the predictors, then **fit a model**\n- Dimension Reduction: We are reducing the number of predictors in the model from p+1 to M+1, where M is less than P\n\t- If $M<<p$ this can significantly reduce the variance of the model\n\t- If $M=p$ this is just least squares\n- We will look at two approaches for this task:\n\t1) Principal Components \n\t2) Partial Least Squares\n\n### Principal Components Regression\n- Principal Components Analysis (PCA): is used to create low-dimensional set of features from a large set of variables\n\t- This is done by selecting the direction of the data that has the most variation \n\t- Following this we project the observations on to the line\n\t- For each principle components, we are looking for the linear combination that yields the highest variance, such that it is orthogonal to the dimension that came before it\n- When the observations are projected onto the principle components, their X value on that line is their **principle components score** \n\t- These can be thought of as single number summaries\n\t\t- EX) A negative principle component score would indicate that this observation has a below-average predictor values, where a positive value would indicate an above average predictor value\n- We can see that a second principle component score would be much closer to zero, this is due to less variation within this dimension\n\n- **Principal Components Regression:** Involves first constructing principle components, followed by fitting a regression model\n\t- Key Idea: small number of dimensions are needed to explain a lot of the variability within the model\n- As more principal components are used, the bias decreases, but the variation increases\n- If you choose the right number of dimensions, it can improve over least squares\n- PCR will do well when the first few principal components are sufficient to capture most of the variation in the predictors as well as the relationship with the response \n- PCR is not a feature selection method\n- One should standardizing each predictor before generating principles components\n\n### Partial Least Squares\n- One drawback of [[#Principal Components Regression]] is that it is fit in an unsupervised way, since $Y$ does not determine the principal components \n\t- Therefore, there is no guarantee that the direction that best explains the variance will also be the best direction for prediction the response \n- Partial Least Squares (PLS): makes use of $Y$ in order to identify new features that not only approximate the old features well, but also that *are related to the response* \n\t- ie) Explains both the response and the predictors\n- PLS places the highest weight on the variables that are most strongly related to the response $$Z_{1} = \\sum^{p}_{j=1}\\theta_{j1}X_{i}$$\n- PLS does not fit the observations as well as PCA, but explains the response better\n- After fitting the first direction, PLS adjusts for $Z_{1}$ by regressing each variable on $Z_{1}$ and taking the residuals, also must be orthogonal \n\t- Interpretation: remaining information that has not been explained \n- In practice preforms no better than [[#Ridge Regression]] or [[#Principal Components Regression]]\n- PLS can reduce bias, it can also increase variance\n\n## Considerations in High Dimensions\n\n### High-Dimensional Data\n- **low-dimension:** when the number of observations far exceeds the number of predictors\n- **High-dimension:** when there are more features than observations \n- Classical approaches are not appropriate in high-dimensions\n### What Goes Wrong in High Dimensions\n- Least squares, and other methods will always result in a perfect fit to the data, ie) overfit\n- A simple least squares regression line is too flexible when there are more features than observations\n- [[#Indirect Estimate]] methods cannot help here because estimating $\\hat{\\sigma}^{2}$ is problematic \n### Regression in high dimensions\n- Methods such [[#Forward Stepwise Selection]], [[#Ridge Regression]], [[#Lasso Regression]], and [[#Principal Components Regression]] are useful in the high-dimensional settings\n- Three important points:\n\t1) Regularization plays a key role in high dimensional data\n\t2) Appropriate tuning parameter is crucial for good predictive performance\n\t3) The test error tend to increase as the dimensionality of the problem increases, unless the additional features are truly associated with the response\n- **Curse of Dimensionality** adding additional signal features that are truly associated with the response will improve the fitted model, adding noise features that are not truly associated with the response will lead to a deterioration in the fitted model, and consequently an increased test set errors\n\n### Interpreting Results in High Dimensions \n- High-dimensional setting, the multicollinearity problem is extreme\n\t- ie) we can never know exactly which variables are truly predictive of the outcome, and we never identify the best coefficients for use in the regression\n- We will only identity one of many models, and it must be validated \n- We cannot use SSE, p-values, $R^2$, or other traditional measures of good fit\n## Introduction\n- Linear regression is a useful tool for predicting a quantitative response\n- Many more fancy statistical learning approaches can be seen as generalizations or extensions of linear regression \n- Linear regression can answer a number of questions:\n\t- The relationship between two variables?\n\t- How strong is the relationship?\n\t- Which variable contributes to the dependent variable?\n\t- How accurately can we estimate the effect?\n\t- How accurately can we predict the future?\n\t- Is the relationship linear?\n\t- How do the variables interact?\n\n## Simple Linear Regression\n- We are looking to predict $Y$ on the basis of a singular predictor $X$\n\t- It assumes there is a linear relationship between $X$ and $Y$ $$Y = \\beta_{0} + \\beta_{1}X$$\n\t- These are also known as *coefficients* or *parameters*\n\t\t- $\\beta_{0}$ = intercept\n\t\t- $\\beta_{1}$ = slope\n\t- $\\hat{y}$ = is a prediction of $Y$ on the basis of $X$\n\n### Estimating the Coefficients\n- In practice the coefficients are unknown \n- Our goal is to obtain coefficients that estimate the data well \n- We measure closeness by *least squares*, we will look to minimize this\n- residual is the difference between the $i^{th}$ observed value and our prediction $$e_{i} = y_{i} - \\hat{y}_{i}$$\n- The least squares approach chooses coefficients that minimize the RSS $$RSS = e^{2}_{1} + e^{2}_{2} + e^{2}_{n}$$\n### Assessing the Accuracy of the Coefficient Estimates\n- We do not expect our model to perfectly predict everything so we have a $\\epsilon$ term\n- $$Y = \\beta_{0} + \\beta_{1}X +\\epsilon$$\n- In real applications, we have access to a set of observations from which we can compute the least squares line; however, the population regression line is unobserved\n- For different subsets of the data we will get different estimations of $Y$\n- An unbiased estimator does not systematically under or over estimate the true parameter \n\t- Over the long term $\\hat{y}$ will converge to $y$\n- How close will our estimate be to the actual:\n\t- Standard error: the average amount that our estimate differs from the actual value\n\t\t- This shrinks with the more observations we have $$SE(\\hat{\\beta_{0}})^{2} = \\sigma^{2}\\left[ \\frac{1}{n} + \\bar{\\frac{x^{2}}{\\sum^{n}_{i=1}(x_{i}-\\bar{x})^2}} \\right]$$\n\t\t- $$SE(\\hat{\\beta_{1}})^{2} = \\frac{\\sigma^{2}}{\\sum^{n}_{i=1}(x_{i}-\\bar{x})^2}$$\n\t\t- We must assume that the error
